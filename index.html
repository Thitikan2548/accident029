ขั้นตอนการอัปโหลดขึ้น GitHub Pages

Dashboard นี้ถูกออกแบบมาในลักษณะ Single File (`index.html`) สามารถโฮสต์ผ่าน GitHub Pages ได้ฟรี 100%!
  1. สร้าง Repository บน GitHub:

    เข้าเว็บ GitHub.com แล้วสร้าง Repository ใหม่ (ตั้งชื่อเช่น health-dashboard)

  2. บันทึกไฟล์เป็นชื่อ index.html:

    คัดลอกซอร์สโค้ดในหน้านี้ทั้งหมด แล้วเซฟเป็นไฟล์ index.html

  3. อัปโหลดไฟล์ขึ้น GitHub:

    กด Upload files บน GitHub Repository แล้วลากไฟล์ index.html ขึ้นไป จากนั้นกด Commit changes

  4. เปิดใช้งาน GitHub Pages:

    ไปที่เมนู Settings > Pages เลือก Branch เป็น main (หรือ master) แล้วกด Save

ข้อแนะนำเพิ่มเติมสำหรับ Google Sheets:

อย่าลืมไปที่ Google Sheets ของคุณ -> เมนู File (ไฟล์) > Share (แชร์) > Publish to web (เผยแพร่ไปยังเว็บ) เลือกรอบเป็น Comma-separated values (.csv) แล้วกด เผยแพร่ เพื่อให้ระบบดึงข้อมูลได้ตลอดเวลา
